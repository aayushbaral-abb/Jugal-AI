<h1 align="center">Jugal-AI</h1>

<p align="center">
  A custom web-based artificial intelligence application built with <strong>React</strong>, <strong>TypeScript</strong>, and <strong>Vite</strong>, utilizing Google's Gemini API for intelligent interactions.
</p>

<p align="center">
  <a href="https://jugalteam.github.io/Jugal-AI/"><strong>🌐 View Live Demo</strong></a>
</p>

---

## 🛠️ Tech Stack & Dependencies

* **Frontend Framework:** React with TypeScript
* **Build Tool:** Vite
* **AI Provider:** Google Gemini API (`@google/genai`)
* **Styling & UI Components:** Custom modular styling and reusable React components

---

## 📁 Project Structure

```text
.
├── components/      # UI components (chat interface, inputs, layout elements)
├── services/        # API service configurations and Gemini integration logic
├── App.tsx          # Main application component & state management
├── constants.ts      # Application configuration values and constants
├── index.html       # HTML entry point
├── index.tsx        # React application bootstrap file
├── metadata.json    # Project metadata
├── types.ts         # TypeScript interface definitions and types
├── vite.config.ts   # Vite configuration settings
└── package.json     # Project dependencies and script commands
